Student Registration & Login System (WPF - C#)
Projectt Overview:

This project is a Student Registration and Login System desktop application built using C# and WPF (Windows Presentation Foundation).
This project was developed as part of my learning journey in C# and desktop application development.

🚀 Features of the software include the following
✅ Student Registration with auto-generated ID and password
✅ Login Authentication System
✅ User Session Management
✅ Student Dashboard Interface
✅ Change Password Functionality
✅ Dynamic UI using UserControls and ContentControls
✅ Personalized Welcome Message

🛠️ Technologies Used
Language: C#
Framework: .NET (WPF)
Architecture Pattern: MVVM (basic implementation)
Data Storage: Local file handling (JSON/Text) while i transition to SQL soon 

STUDENT-REGISTRATION-LOGIN-SYSTEM/
│
├── DATABASE/          # Handles saving and retrieving data
├── OBJECT/            # Models (e.g., Student class)
├── VIEWMODEL/         # Application logic (MVVM)
├── PAGES/             # UI Pages (Login, Dashboard, etc.)
├── UserControls/      # Reusable UI components
└── App.xaml           # Application entry point


🔑 How It Works presently
A USer(student) registers → system generates ID and password
User data is stored locally using Json file
Student logs in using credentials
System validates and creates a session 
Dashboard displays user-specific information
User can change password and interact with features such as Register Course, Hostel Allocation, Update Biodata record etc.
🎯 What I Learned


Through this project, I gained practical experience in:

Building authentication systems
Managing user sessions in desktop apps
Passing data between pages in WPF
Structuring a real-world C# application
Using UserControls for dynamic UI

⚠️ Limitations
Uses local file storage instead of a database
No password encryption (for learning purposes only)
UI design is basic and can be improved
